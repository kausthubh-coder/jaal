# M0: plain Chromium builds on Windows, 2026-11-09

Plain Chromium 156.0.8078.88, no patches, built on the Windows laptop (Ryzen 9 8945HS, 16 threads, 15 GB RAM). The engine plan is [docs/engine.md](../../docs/engine.md).

## Result

Passed on Windows. `out\Release\chrome.exe` opened `bakeoff/pages/page-1.html` with the sandbox on and quit cleanly.

- Window title: `Test page 1 - Chromium`.
- Processes: 1 browser, 6 renderers, 1 GPU, 2 utility, 1 crashpad. No `--no-sandbox` on any command line.
- Screenshot: [screens/m0-chrome-156-windows.png](screens/m0-chrome-156-windows.png).
- Launched with a throwaway profile under `C:\src\chromium\m0-profile`, deleted afterwards.

Not checked: the Mac build (Depot), any page that needs the network, extensions, and everything past "it opens a page".

## Build

| Setting | Value |
|---|---|
| Source | `C:\src\chromium\src`, tag `156.0.8078.88`, fetched with `--no-history` (15 min, about 29 GB) |
| Toolchain | Visual Studio 2026 Community 18.11 with ATL/MFC, Windows SDK 10.0.26100, depot_tools at `C:\src\depot_tools`, `DEPOT_TOOLS_WIN_TOOLCHAIN=0` |
| GN args | `is_debug=false`, `is_component_build=false`, `symbol_level=0`, `blink_symbol_level=0`, `v8_symbol_level=0`. Everything else default |
| Build tool | siso (autoninja), `-j 12`. With 12 jobs the laptop sat at about 2 GB of RAM free and 85% CPU |
| Build script | `C:\src\chromium\build-chrome.cmd`, logs in `C:\src\chromium\build*.log` |

Three runs, because of one build failure and one stop for class:

| Run | Wall time | Steps | Outcome |
|---|---|---|---|
| 1 | 34 min | 15,842 done | Failed at one step: a DevTools TypeScript check ran before the step that writes a file it reads (`insights-tsconfig.ref.json` wants `legacy-javascript/bundle-tsconfig.ref.json`). The same step passed alone afterwards, so it is a build-order race in upstream Chromium. Not patched |
| 2 | 3 h 23 min | 18,863 done, 32,087 left at the stop | Stopped by PID at 12:21 so the laptop could be closed |
| 3 | 1 h 43 min | 14,155 left at restart, all done | Succeeded |

About 5 h 40 min of building in total, over three runs on one day with the laptop also in use. That is one data point, not a benchmark. Incremental builds after a change are untested.

Disk after the build: 196.7 GB free, so source plus build output took about 46 GB.
